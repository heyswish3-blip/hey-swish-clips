Privacy Policy

Last updated: September 2026. App name: Hey Swish Clips.

This policy explains what data Hey Swish Clips uses when you connect your own TikTok or YouTube account, why it is used, where it is stored, and what rights you have. Hey Swish Clips runs locally on your own computer; there is no hosted service that collects your data, no analytics, and no tracking on this website.

1. TikTok Login Kit

When you connect a TikTok account, the app uses TikTok Login Kit (OAuth). TikTok shows you a consent screen where you approve the requested scopes. The app receives:

  • basic account identity (user.info.basic): the account identifier and nickname, used only to confirm which account is connected and to address API calls to it;
  • an access token and a refresh token, used only to call TikTok APIs on your behalf when you run the tool.

2. TikTok Content Posting API

When you publish a clip to TikTok, the app uses the official Content Posting API (video.publish) and sends:

  • the video file you selected, its caption, and the privacy setting you chose (private by default until your app is approved for public posting);
  • account capability data read from TikTok immediately before posting (available privacy options and posting limits), used only to validate that the post is allowed.

TikTok returns a publish identifier, which is stored locally so the tool can track posting status. Videos are posted only when you explicitly run the tool.

3. YouTube OAuth and YouTube Data API

When you connect a YouTube channel, the app uses Google OAuth (upload scope) and the official YouTube Data API. Google shows you a consent screen first. The app receives:

  • an access token and a refresh token, used only to upload videos you select;
  • uploads are created as private by default.

YouTube returns a video identifier, which is stored locally so the tool can track upload status.

4. What other data is used

  • Your source material: video files and transcripts you provide stay on your computer and are processed locally.
  • Clip metadata: titles, captions and quality scores generated locally to prepare posts.
  • Technical logs: local log files used for debugging. They never contain tokens or passwords.

5. Purpose

All data is used solely to set up and operate your own content pipeline: connecting your accounts, preparing clips, and publishing content you approve to those accounts. Data is never used for advertising, profiling, or any other purpose.

6. Storage and secrets

  • Tokens and API secrets are stored only in local configuration files on your own computer (excluded from public source control) and, for automation workflows, in the encrypted credential store of your own local automation setup.
  • Secrets are never displayed publicly, never committed to public code, never sent in URLs where avoidable, and never included in log files.
  • Removing the local configuration files deletes the stored secrets from the tool.

7. Sharing

Data is shared only with the platforms you connect (TikTok, Google/YouTube), and only through their official APIs when you run the tool. Nothing is sold or shared with other third parties. This website itself collects nothing.

8. Retention

Local working files are kept according to the tool's documented retention rules (failed records expire; completed results are kept). You can delete any local file at any time. Revoking access in your TikTok or Google account settings immediately stops the tool from acting on your behalf; already published content must be removed in the respective platform app.

9. Your rights

Depending on where you live, you may have the right to access, correct, or delete your data, and to withdraw consent at any time. Because the tool stores everything locally with you, you can exercise these rights directly: inspect or delete the local files, revoke the app's access in your TikTok or Google account settings, or stop using the tool. To ask a question about this policy, open an issue in the public GitHub repository linked below.

10. Children

Hey Swish Clips is a creator tool and is not directed at children. It must only be used in line with TikTok's and Google's own age requirements.

11. Changes

If this policy changes materially, the updated version will be published on this page with a new date.

12. Contact

Questions about this policy: please open an issue at github.com/heyswish3-blip/hey-swish-clips. No personal contact details are published here.
